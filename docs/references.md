# References and how they are used

These are sources for methods and data provenance, not evidence that the code or its results have been independently validated. Source metadata and available primary text were checked for this extension on 2026-10-20.

1. **Varma, S., & Simon, R. (2006).** Bias in error estimation when using cross-validation for model selection. *BMC Bioinformatics, 7*, 91. [doi:10.1186/1471-2105-7-91](https://doi.org/10.1186/1471-2105-7-91). Original methods study supporting separation of parameter tuning from performance estimation.
2. **Breiman, L. (2001).** Random forests. *Machine Learning, 45*, 5–32. [doi:10.1023/A:1010933404324](https://doi.org/10.1023/A:1010933404324). Original description of the model family; the repository's implementation is scikit-learn's classifier and limited search, not a reproduction of every analysis in this paper.
3. **Wilson, E. B. (1927).** Probable inference, the law of succession, and statistical inference. *Journal of the American Statistical Association, 22*(158), 209–212. [doi:10.1080/01621459.1927.10502953](https://doi.org/10.1080/01621459.1927.10502953). Source of the score-interval approach used for displayed bin fractions; interval assumptions and scope are stated in the methods.
4. **Collins, G. S., et al. (2024).** TRIPOD+AI statement: updated guidance for reporting clinical prediction models that use regression or machine learning methods. *BMJ, 385*, e078378. [doi:10.1136/bmj-2023-078378](https://doi.org/10.1136/bmj-2023-078378). [Original article](https://pmc.ncbi.nlm.nih.gov/articles/PMC11019967/). Used to improve reporting transparency. The affiliation correction `bmj.q902` is not the underlying methods statement.
5. **Moons, K. G. M., et al. (2025).** PROBAST+AI: an updated quality, risk of bias, and applicability assessment tool for prediction models using regression or artificial intelligence methods. *BMJ, 388*, e082505. [doi:10.1136/bmj-2024-082505](https://doi.org/10.1136/bmj-2024-082505). [Full text](https://pmc.ncbi.nlm.nih.gov/articles/PMC11931409/). Used to identify unresolved questions about sample selection, model development, and applicability; not applied here as a formal certification.
6. **Van Calster, B., McLernon, D. J., van Smeden, M., Wynants, L., & Steyerberg, E. W. (2019).** Calibration: the Achilles heel of predictive analytics. *BMC Medicine, 17*, 230. [doi:10.1186/s12916-019-1466-7](https://doi.org/10.1186/s12916-019-1466-7). Peer-reviewed methodological guidance distinguishing calibration from discrimination and explaining small-sample limits.
7. **Wolberg, W., Mangasarian, O., Street, N., & Street, W. (1993).** Breast Cancer Wisconsin (Diagnostic) [Dataset]. UCI Machine Learning Repository. [doi:10.24432/C5DW2B](https://doi.org/10.24432/C5DW2B). Data source and attribution; see the separate [data-provenance note](data-provenance.md).

Implementation references: scikit-learn's [dataset loader](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_breast_cancer.html), [data-leakage guide](https://scikit-learn.org/stable/common_pitfalls.html#data-leakage), [GridSearchCV](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.GridSearchCV.html), and [RandomForestClassifier](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.RandomForestClassifier.html). The dependency file pins the version actually run; a current documentation page can describe a newer release in future.


## Additional sources for the biology and prevalence extension

- **Street, W. N., Wolberg, W. H., & Mangasarian, O. L. (1993).** Nuclear feature extraction for breast tumor diagnosis. *Proceedings of SPIE, 1905*, 861–870. [doi:10.1117/12.148698](https://doi.org/10.1117/12.148698). Original image-feature work; the current analysis starts from archived numerical summaries.
- **Lange, K., & Brunner, E. (2013).** Analysis of predictive values based on individual risk factors in multi-modality trials. *Diagnostics, 3*(1), 192–209. [doi:10.3390/diagnostics3010192](https://doi.org/10.3390/diagnostics3010192). Supports the Bayes predictive-value equations; the repository does not implement its full trial-analysis methods.
- **Lipton, Z., Wang, Y.-X., & Smola, A. (2018).** Detecting and correcting for label shift with black box predictors. *Proceedings of Machine Learning Research, 80*, 3122–3130. [Primary conference paper](https://proceedings.mlr.press/v80/lipton18a.html). Defines the class-conditional stability assumption; no shift detection or correction is performed here.
- **Murad, M. H., et al. (2023).** The association of sensitivity and specificity with disease prevalence: analysis of 6909 studies of diagnostic test accuracy. *CMAJ, 195*, E925–E931. [doi:10.1503/cmaj.221802](https://doi.org/10.1503/cmaj.221802). Primary meta-epidemiological analysis motivating caution about invariant operating characteristics; it does not establish their behavior in this particular benchmark.
